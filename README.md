# MACH: Multi-Attribute Catchment Hydrometeorological dataset
**MACH** is large-sample hydrometeorological dataset spanning 1,014 watersheds across the United States. It integrates daily meteorological forcings, streamflow observations, and a comprehensive suite of watershed attributes into a unified basin-scale resource. 

The dataset covers 1980-2023 (44 years) for all catchments, with extended records back to 1948 (75 years total) for 395 basins. 

MACH includes:
<ul>
  <li>Daily meteorological forcings</li>
  <li>Daily streamflow observations</li>
  <li>Watershed attributes (topography, soils, geology, land cover, anthropogenic influences)</li>
  <li>Hydroclimatic indices and derived metrics</li>
</ul>

The dataset is designed to support:
<ul>
  <li>Climate and runoff analyses</li>
  <li>Hydrologic model calibration and benchmarking</li>
  <li>Sensitivity and attribution studies</li>
  <li>Long-term watershed change assessment</li>
  <li>Large-sample hydrology research</li>
</ul>

MACH provides a consistent, high-resolution framework for advancing hydroclimatic science and data-driven water research. 
## Data Access
:point_right: The MACH dataset is publicly archived on [Zenodo](https://zenodo.org/records/18686475). 
Each release is versioned and permanently archived. 
Please use the DOI corresponding to the version used in your analysis.
